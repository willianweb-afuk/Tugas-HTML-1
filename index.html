Hubungi Kami

Materi HTML

Apa itu HTML?

HTML atau HyperText Markup Language adalah bahasa markup yang digunakan untuk membuat struktur dasar halaman website.

Fungsi HTML

  • Membuat judul
  • Membuat paragraf
  • Membuat gambar
  • Membuat link
  • Membuat tabel
  • Membuat formulir

Contoh HTML

<!DOCTYPE html> <html> <body> <h1>Halo Dunia</h1> <p>Ini website saya.</p> </body> </html>

Materi CSS

Apa itu CSS?

CSS atau Cascading Style Sheets digunakan untuk mengatur tampilan dan desain website.

Fungsi CSS

  • Mengatur warna
  • Mengatur ukuran teks
  • Mengatur jarak
  • Mengatur posisi elemen
  • Membuat tampilan responsif

Contoh CSS

body { font-family: Arial; background: white; } h1 { color: green; }

Materi JavaScript

Apa itu JavaScript?

JavaScript adalah bahasa pemrograman yang digunakan untuk membuat website menjadi interaktif dan dinamis.

Fungsi JavaScript

  • Membuat tombol interaktif
  • Menampilkan pesan
  • Memproses input pengguna
  • Mengubah isi halaman
  • Membuat fitur dinamis

Contoh JavaScript

function sapa() { alert("Halo, selamat datang!"); }

Materi Bootstrap

Apa itu Bootstrap?

Bootstrap adalah framework CSS yang menyediakan berbagai komponen siap pakai untuk membantu membuat website dengan lebih cepat dan responsif.

Fungsi Bootstrap

  • Membuat layout website
  • Membuat tombol
  • Membuat navbar
  • Membuat card
  • Membuat website responsif

Contoh Bootstrap

<button class="btn btn-primary"> Klik Saya </button>

Contoh Navbar Bootstrap

<nav class="navbar navbar-expand-lg"> <a class="navbar-brand"> Proweb </a> </nav>
